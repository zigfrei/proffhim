# proffhim
Разработка веб страницы фирмы ПроффХим

## Новогоднее оформление

Локально добавьте `WINTER_DECORATIONS=true` в `.env.local` и перезапустите
`pnpm dev`.

Для production задайте переменную репозитория GitHub Actions
`WINTER_DECORATIONS=true` и запустите **Deploy production** из ветки `prod`.
После праздников задайте `WINTER_DECORATIONS=false` или удалите переменную
и повторно запустите тот же workflow. Переключатель управляет снегопадом, декоративными
изображениями и выбором логотипа. Обычный логотип хранится в
`src/assets/icons/logo-old.svg`.

## Журнал изменений

Перед коммитом фиксируйте существенные изменения в [CHANGELOG.md](./CHANGELOG.md): что поменяли, когда и как проверили.
Объединяйте связанные изменения в одну запись, без перечисления каждой мелкой или промежуточной правки.
Даты — по Europe/Minsk; новые даты размещаются сверху.
