# proffhim
Разработка веб страницы фирмы ПроффХим

## Журнал изменений

Все изменения проекта фиксируются в [CHANGELOG.md](./CHANGELOG.md): что поменяли, когда и как проверили.
После изменений кода, контента, конфигурации или документации дополняйте запись за текущий день
(часовой пояс Europe/Minsk). Новые даты размещаются сверху.
